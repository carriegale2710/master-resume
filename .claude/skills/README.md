# Resume Skills for AI Agents

> Copied from carriegale2710/ResumeSkills. Also available in carriegale2710/skills-library. Original repository maintained by Paramchoudhary.

AI agent skills for resume writing, ATS review, interview prep and job search.

## What are Skills?

Markdown files that give agents a workflow for one task. Claude Code loads them from this folder.
