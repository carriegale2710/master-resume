Linkedin header vs cv

| Where | Recommended wording | Why |
| :---- | :---- | :---- |
| LinkedIn headline | **Full-Stack Developer | React, TypeScript, Node.js, Java, Spring Boot, SQL | Graduate Certificate in IT (Computer Science)** | Optimises for role and technical keyword searches while staying factually accurate |
| CV headline | **Junior Full-Stack Software Engineer | TypeScript, React, Node.js, Java, Spring Boot, SQL, AWS** | “Junior” is useful here because each application is for a defined level and should mirror the job title |
| LinkedIn Open to Work preferences | Select **Junior Software Engineer**, **Junior Full-Stack Developer**, **Software Engineer**, and **Full-Stack Developer** | Lets recruiters find the candidate under both entry-level and broader job-title searches |
| Education section | **Graduate Certificate in IT (Computer Science)**, then **Bachelor of Arts (Design & Digital Cultures)** | Provides complete, unambiguous qualification context |
